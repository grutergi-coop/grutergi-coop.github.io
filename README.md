# 그루터기 사회적협동조합 홈페이지

- 주소: https://grutergi-coop.github.io
- 호스팅: GitHub Pages (grutergi-coop/grutergi-coop.github.io, main)
- 데이터·로그인: Firebase 프로젝트 `grutergi-coop` (Firestore asia-northeast3, 이메일 링크 로그인)

## 화면
| 주소 | 내용 |
|---|---|
| `/` | 첫 화면 (내용은 관리자 화면 › 홈 화면에서 고침) · 서면 문의 |
| `/notice/` | 공고 게시판 · `/notice/view.html?id=…` 공고 원문 |
| `/member/` | 조합원 전용 (이메일 링크 로그인 → 확인 신청 → 승인) |
| `/admin/` | 관리자 화면 (검색 노출 안 함) |

## 관리자 화면
- 대시보드: 방문 수(14일, 기기·화면별), 새 문의, 지금 접속 중, 오류
- 홈 화면: 첫 화면의 모든 글·연혁·목록 수정, 공고 띠 켜기/끄기, 타임머신 되돌리기
- 공고: 작성·수정·게시/비공개 (삭제 없음, 변경 사유가 공개 변경 이력에 남음)
- 문의: 새 문의/답변 중/답변 완료, 내부 메모, 답변 완료 1년 뒤 파기
- 조합원: 승인, 유형·출자 좌수·납입 여부
- 보안·기록: 접속 현황, 로그인 기록, 활동 기록(감사 로그), 오류 알림판, 자동 로그아웃 시간

## 보안 원칙
- 권한은 화면이 아니라 `firestore.rules`가 지킴 (기본 전부 거부)
- 관리자 = `admins/{UID}` 문서가 있는 계정. 콘솔에서만 추가 가능
- 모든 내용은 글자로만 표시 (HTML 해석 없음), 링크 주소 검사
- 모든 페이지 CSP 적용, 관리자는 브라우저 닫으면 로그아웃 + 미사용 시 자동 로그아웃
- 문의: 숨은 칸(봇 차단)·3초 대기·길이 제한, 개인정보 수집·이용 동의 필수
- IP 주소는 기록하지 않음

## 처음 설정
1. Firebase 콘솔 › Firestore › 규칙에 `firestore.rules` 전문 붙여 넣고 게시
2. `/admin/`에서 로그인 → 보이는 UID를 `admins` 컬렉션 문서 ID로 추가
3. 관리자 화면 › 홈 화면 › "기본 내용 넣기"
