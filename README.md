# 그루터기 사회적협동조합 홈페이지

깃허브 페이지(공개 화면) + 파이어베이스(조합원 로그인) 구성입니다.

- index.html 첫 화면
- notice/ 공고 게시판과 공고 원문
- member/ 조합원 로그인 (이메일 링크)
- css/style.css 공통 스타일
- js/firebase-config.js 파이어베이스 설정값
- js/member.js 조합원 화면 동작
- firestore.rules Firestore 보안 규칙
- assets/ 로고와 수채화 이미지

노란 칸(class="fill")은 확정 후 채울 자리입니다.
저장소는 공개입니다. 조합원 개인정보는 저장소에 두지 않고 Firestore에만 둡니다.
